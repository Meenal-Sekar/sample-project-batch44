Git vs Github

What is github? GitHub is a code hosting platform for version control and collaboration. It lets you and others work together on projects from anywhere. Git: Git is a distributed version control system for tracking changes in source code during software development. It is designed for coordinating work among programmers, but it can be used to track changes in any set of files Git add Git commit Git push Git fetch Git checkout Git merge Features of git ----------------- Git is a software Git is a command-line tool Git is installed locally on the system. Git is maintained by Linux. Git is focused on code sharing Git is open source Features of GitHub ------------------- Github is a service Github is a graphical user interface Github is hosted on the web. repositories
